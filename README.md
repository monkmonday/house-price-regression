# 🏠 House Price Prediction - Regression Project

## 📌 Overview

This project predicts house prices using multiple regression models and compares their performance.

---

## ⚙️ Models Used

* Linear Regression
* Ridge Regression
* Lasso Regression

---

## 🔍 Techniques Applied

* Exploratory Data Analysis (EDA)
* Feature Selection using Correlation
* Train-Test Split
* K-Fold Cross Validation
* Hyperparameter Tuning (GridSearchCV)

---

## 📊 Results

| Model             | R² Score |
| ----------------- | -------- |
| Linear Regression | 0.718    |
| Ridge Regression  | 0.717    |
| Lasso Regression  | 0.671    |

---

## 🧠 Key Insights

* RM and LSTAT are the most important features
* Linear Regression performed best
* Ridge provides more stable results

---

## 🚀 Conclusion

Linear Regression gave the best performance, while Ridge offered stability and Lasso helped with feature selection.
